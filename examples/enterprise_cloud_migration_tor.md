# ข้อกำหนดและขอบเขตของงาน (Terms of Reference : TOR)
## โครงการจ้างพัฒนาระบบคลาวด์และยกระดับโครงสร้างพื้นฐานดิจิทัล (Enterprise Cloud Modernization)

---

### ข้อ 1. ความเป็นมาและวัตถุประสงค์
หน่วยงานมีความประสงค์จะดำเนินการจ้างพัฒนาระบบคลาวด์และยกระดับสถาปัตยกรรมดิจิทัลขององค์กร เพื่อรองรับการประมวลผลข้อมูลปริมาณสูง (High-Throughput Streaming) การทำงานแบบคอนเทนเนอร์ (Kubernetes & Microservices) และเพิ่มประสิทธิภาพในการให้บริการเชื่อมโยงข้อมูลระหว่างสายงานธุรกิจ

### ข้อ 2. คุณสมบัติของผู้ยื่นข้อเสนอ
2.1 ต้องเป็นนิติบุคคลที่จดทะเบียนถูกต้องตามกฎหมายไทย มีทุนจดทะเบียนชำระแล้วไม่น้อยกว่า 20,000,000 บาท  
2.2 ต้องมีผลงานการพัฒนาระบบคลาวด์หรือโครงสร้างพื้นฐานระดับองค์กร ที่มีมูลค่าสัญญาไม่น้อยกว่า 15,000,000 บาท ในสัญญาเดียว ต่อหน่วยงานรัฐหรือรัฐวิสาหกิจ หรือบริษัทในตลาดหลักทรัพย์  
2.3 บุคลากรหลักของโครงการต้องมีใบรับรองมาตรฐานวิชาชีพสากล (เช่น AWS Certified Solutions Architect Professional, CKA, หรือเทียบเท่า) ไม่น้อยกว่า 3 คน

### ข้อ 3. ขอบเขตของงาน (Scope of Work)
3.1 ผู้รับจ้างต้องดำเนินการย้ายระบบ (Cloud Migration) จากระบบ On-Premise เดิมขึ้นสู่ระบบ Enterprise Cloud Platform ตามสถาปัตยกรรม Well-Architected Framework  
3.2 ผู้รับจ้างต้องพัฒนา API Gateway และเชื่อมโยงข้อมูลกับระบบ SAP และระบบฐานข้อมูลหลักขององค์กร  
3.3 ผู้รับจ้างต้องดูแล บำรุงรักษา และพัฒนาระบบ รวมถึงงานอื่นๆ ที่ผู้ว่าจ้างมอบหมายเพิ่มเติม และรวมถึงระบบอื่นๆ ที่จะเกิดขึ้นในอนาคต โดยไม่มีค่าใช้จ่ายเพิ่มเติม  
3.4 ทรัพย์สินทางปัญญาทั้งหมด ซอร์สโค้ด (Source Code) สิทธิบัตร แบบพิมพ์เขียว และไลบรารีที่สร้างขึ้นภายใต้สัญญานี้ ให้ตกเป็นกรรมสิทธิ์ของผู้ว่าจ้างแต่เพียงผู้เดียว

### ข้อ 4. ระยะเวลาดำเนินการและการส่งมอบงาน (Milestones)
การดำเนินงานแบ่งออกเป็น 3 งวดงาน รวมระยะเวลา 180 วัน นับถัดจากวันลงนามในสัญญา:
- **งวดที่ 1 (ภายใน 30 วัน):** ส่งมอบแผนการบริหารโครงการ (Project Charter) และพิมพ์เขียวสถาปัตยกรรมระบบ (Cloud Architecture Blueprint) จ่ายเงินร้อยละ 20 ของมูลค่าสัญญา
- **งวดที่ 2 (ภายใน 120 วัน):** ดำเนินการติดตั้งระบบ พัฒนา API Gateway เชื่อมโยงระบบฐานข้อมูล และทดสอบระบบนำร่อง จ่ายเงินร้อยละ 40 ของมูลค่าสัญญา
- **งวดที่ 3 (ภายใน 180 วัน):** ดำเนินการย้ายระบบทั้งหมดขึ้นใช้งานจริง (Production Go-Live), ทำการทดสอบ UAT และฝึกอบรมบุคลากร จ่ายเงินร้อยละ 40 ของมูลค่าสัญญา

การตรวจรับในแต่ละงวดงาน ต้องได้รับการอนุมัติจนเป็นที่พึงพอใจของคณะกรรมการตรวจรับพัสดุ ตามดุลยพินิจของคณะกรรมการ จึงจะถือว่าการส่งมอบงานเสร็จสมบูรณ์

### ข้อ 5. ข้อกำหนดระดับการให้บริการ (Service Level Agreement : SLA)
5.1 ผู้รับจ้างต้องจัดให้มีทีมงานสนับสนุนด้านเทคนิคตลอด 24 ชั่วโมง ทุกวัน (24x7 Technical Support)  
5.2 กรณีเกิดปัญหาขั้นวิกฤต (Priority 1 - Critical Outage) ที่กระทบต่อการให้บริการหลัก ผู้รับจ้างต้องเข้าแก้ไขปัญหาภายใน 1 ชั่วโมงตลอด 24 ชั่วโมง และต้องทำให้ระบบกลับคืนสู่สภาพเดิมภายใน 2 ชั่วโมง (MTTR <= 2 Hours)  
5.3 ระบบต้องมีความพร้อมใช้งาน (Availability Uptime) ไม่ต่ำกว่าร้อยละ 99.95 ต่อเดือน  
5.4 หากไม่สามารถปฏิบัติตามระดับการให้บริการตามที่กำหนด ผู้รับจ้างยินยอมให้ปรับลดค่าจ้างรายเดือนหรือถูกปรับตามเงื่อนไขความเสียหาย

### ข้อ 6. อัตราค่าปรับและการบอกเลิกสัญญา (Liquidated Damages)
6.1 หากผู้รับจ้างไม่สามารถส่งมอบงานให้แล้วเสร็จภายในระยะเวลาที่กำหนดตามสัญญา ผู้รับจ้างจะต้องชำระค่าปรับเป็นรายวันในอัตราร้อยละ 0.1 ต่อวัน คิดจากราคาสัญญาทั้งหมด จนกว่าจะส่งมอบงานแล้วเสร็จถูกต้องตามเงื่อนไขของสัญญา  
6.2 หากค่าปรับสะสมมีจำนวนเกินร้อยละ 10 ของมูลค่าสัญญาทั้งหมด ผู้ว่าจ้างมีสิทธิบอกเลิกสัญญาและริบหลักประกันสัญญาทันทีตามมาตรา 103 แห่งพระราชบัญญัติการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560
